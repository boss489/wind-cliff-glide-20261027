# 바람절벽 활공

설치 없이 `index.html`을 브라우저에서 열어 플레이하는 한국어 단일 화면 액션 게임입니다. 외부 네트워크, 빌드 도구, 라이브러리 없이 동작합니다.

## 플레이

- ← / → 또는 A / D: 좌우 조향. 마우스는 게임 화면 왼쪽·오른쪽을 누르고, 터치는 화면 또는 아래의 큰 버튼을 누릅니다.
- Space / 우클릭 / ✦: 저장한 기류를 1회 해제하여 36프레임(0.6초) 동안 하강 속도를 줄입니다. 청록색 기류 원(✦)을 지나면 다시 1회 충전됩니다.
- B 또는 별도 ▼ 급강하 부스트 버튼을 누르고 있는 동안 더 빨리 내려갑니다(평상시 11 → 부스트 15 단위/프레임). 기류 부양 중에는 부양이 우선합니다. 부스트 중 암벽 스침 임시 점수는 2배지만 안전 거리로 벗어나야 확정됩니다. 사용 횟수 제한은 없습니다.
- 1–23번 협곡의 출구를 통과해도 캐릭터·카메라의 세계 좌표가 처음으로 돌아가지 않습니다. 같은 비행으로 다음 협곡에 이어서 내려가며 조향·부스트 홀드, 좌우 속도, 확정 점수, 충전과 남은 부양 효과가 유지됩니다. 협곡별 60초 제한만 다음 구간에서 다시 시작합니다. 실패 시 재도전 화면, 24번 완주 시 최종 결과 화면이 표시됩니다.
- P / Esc / Ⅱ: 일시정지. 상단 헤더에서 움직임 줄이기(`모션 표준/감소`)와 효과음(`켜짐/음소거`)을 언제든 전환할 수 있습니다. 벽이나 붉은 이동 바위에 닿으면 실패, 60초 안에 협곡 아래 황금 출구 관문에 도달하면 성공합니다.
- 암벽 안쪽 주황색 스침 구간으로 가깝게 날면 임시 점수를 얻고, 협곡 중앙(안전 거리)으로 충분히 떨어져야 확정 점수로 옮겨집니다. 추락·시간 초과·출구 통과 때 남은 임시 점수는 버립니다.
- 24개 서로 다른 고정 협곡. 1–6 고요한 기류, 7–14 간헐적 횡풍, 15–24 더 센 횡풍과 이동 바위. 기본 협곡 폭은 기존 278/260/244/272/252/232에서 274/256/240/268/248/228로 각 4 단위 축소했고, 8구간마다 추가로 5 단위 좁아지는 규칙은 유지했습니다. 중심 경로의 좌우 굴곡은 직전 공개 버전(원본 대비 1.15배)을 기준으로 1번에서 20% 더, 24번에서 35% 더 꺾이도록 구간마다 선형으로 증가합니다(원본 대비 1.38~1.5525배). 속도·충돌 반경·점수·횡풍·장애물은 그대로입니다. 후반의 급격한 굴곡은 부스트를 계속 누른 채로 통과하는 경로를 보장하지 않으므로 필요하면 부스트를 놓고 조향해야 합니다. 협곡 진척은 이 브라우저의 `localStorage`에 보관됩니다. 브라우저 저장소가 차단된 환경에서는 플레이는 가능하지만 진척이 유지되지 않습니다.

## 검증

```sh
node tests/core.test.cjs
```

고정 60Hz 상태 전이, 24개 경로 구별·중심 경로 도달, 충돌 경계, 기류 1회 사용, 점수 확정/취소, 출구/시간 초과, 시드 재현성을 검사합니다. 브라우저는 `index.html`로 독립 실행하며 게임은 프레임 타이머의 누산기에서 1/60초 고정 단계로 전이합니다. 탭이 느려져 초당 렌더링이 뒤처지면 안전을 위해 밀린 단계 일부를 버립니다(실시간 경과와 게임 내 틱이 달라질 수 있음). 그래픽, 벡터 지형과 Web Audio 효과음은 전부 코드로 새로 작성했습니다.

## 파일

`index.html` 화면·조작, `style.css` 반응형 레이아웃, `game.js` 순수 시뮬레이션과 레벨, `app.js` 렌더러·입력·저장·음향, `tests/core.test.cjs` 상태 검증, `LICENSE` 이용 조건.
